# Hybrid-Quantum-Financial-Forecasting

This repository contains the dataset and trained models used in the study:

"Hybrid Quantum-Classical Neural Architectures for Financial Time-Series Forecasting"

## Repository Contents

### Dataset

The repository includes processed S&P 500 financial time-series data with technical indicators:

- Open
- High
- Low
- Close
- Volume
- SMA_50
- SMA_200
- RSI
- MACD
- Signal
- Momentum

### Trained Models

Included trained models:

- LSTM+QNN
- GRU+QNN
- QENN
- QSVM
- BiLSTM
- QLSTM
- QGRU
- CNN+QNN
- CNN+LSTM+QNN
- CNN+GRU+QNN

## Data Source

Historical market data were obtained from Yahoo Finance using the yfinance Python API.

## Purpose

The repository is provided to support reproducibility and transparency of the experimental results reported in the associated manuscript.
